# ai-trading-analyst

Bundled snapshot of nine ticker-based analyst skills from
[zubair-trabzada/ai-trading-claude](https://github.com/zubair-trabzada/ai-trading-claude)
(MIT). These power the **Analysis** tab in the web app — pick a skill, give it
a ticker, get an HTML report. The wrapper prompt is in
`app/trade_plan_runner.py::_build_prompt`.

See `NOTICE` for the upstream commit pinned, the list of vendored vs.
not-vendored skills, and the local-modifications policy. See `LICENSE` for the
MIT terms.
